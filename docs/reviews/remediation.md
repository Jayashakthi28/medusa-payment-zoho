## Residual, documented limitations

- **No live Zoho sandbox in CI.** Use `scripts/smoke.mjs` with merchant credentials.
- **No full Medusa app boot fixture.** The provider contract and module identity are
  tested directly; the Medusa webhook route is framework-owned.
- **No durable webhook event store.** Duplicate delivery maps to the same action and is
  idempotent in Medusa's workflow; external side effects need a merchant-owned dedupe.
- **Medusa 2.22 ignores non-success webhook actions.** Terminal failures remain pending
  in Medusa until reconciled or retried; this is Medusa behavior, not a silent success.
- **A custom `scriptUrl` executes third-party JavaScript.** It is an explicit developer
  option; never pass user input to it.
- **No real-browser E2E or live refund settlement test.** The widget is verified in
  jsdom and the refund semantics are unit-tested against the documented API.
